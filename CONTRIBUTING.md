## Toolchain setup

### Windows (primary platform)

Run in PowerShell. `winget` ships with Windows 11.

```powershell
# 1. C++ build tools (MSVC + Windows SDK), needed by Rust and by MuPDF.
winget install --id Microsoft.VisualStudio.2022.BuildTools --override "--quiet --wait --add Microsoft.VisualStudio.Workload.VCTools --includeRecommended"

# 2. Rust (stable, MSVC target) and LLVM/Clang (bindgen needs libclang to build mupdf-sys).
winget install --id Rustlang.Rustup
winget install --id LLVM.LLVM
```

Open a **new** terminal so `PATH` is refreshed, `cd` into the repository, then:

```powershell
rustup default stable-x86_64-pc-windows-msvc
[Environment]::SetEnvironmentVariable("LIBCLANG_PATH", "C:\Program Files\LLVM\bin", "User")

# 3. pnpm through corepack (Node.js >= 22). The exact version is pinned in package.json.
corepack enable

# 4. Cargo tools.
cargo install --locked cargo-nextest cargo-deny tauri-cli
```

WebView2 is preinstalled on Windows 11.

### macOS

```bash
xcode-select --install
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
corepack enable
cargo install --locked cargo-nextest cargo-deny tauri-cli
```

### Linux (Debian/Ubuntu)

```bash
sudo apt install libwebkit2gtk-4.1-dev libxdo-dev libssl-dev libayatana-appindicator3-dev librsvg2-dev build-essential clang
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
corepack enable
cargo install --locked cargo-nextest cargo-deny tauri-cli
```

## Everyday commands

```bash
pnpm install                  # frontend dependencies
pnpm tauri dev                # run the app with hot reload
pnpm test                     # frontend unit tests (vitest)
pnpm lint                     # Biome
cargo nextest run --workspace # Rust tests
cargo clippy --workspace --all-targets -- -D warnings
cargo fmt --all
cargo deny check              # licenses and advisories
pnpm gen:bindings             # regenerate ui/src/bindings.ts from the Rust IPC commands
```

`ui/src/bindings.ts` is generated by `tauri-specta` and committed. Never edit it by hand; CI fails if it is out of date.

## Pull requests

- One change, one purpose. Commits follow [Conventional Commits](https://www.conventionalcommits.org/) (`feat(render): …`, `fix(latex): …`).
- Code, identifiers, comments and commit messages in English; product documentation may be in Spanish.
- Changes to `crates/render`, `crates/doc` or `ui/src/viewer` must include `cargo bench -p render` numbers before and after. Regressions above 5 % need an explicit justification.
- New dependencies must be justified and pass `cargo deny check` (AGPL-compatible licenses only).
- Architecture or stack changes need an ADR in `docs/adr/`.
