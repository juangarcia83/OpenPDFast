# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

In short: be respectful and welcoming, give and accept constructive feedback, and focus on what is best for the community. Harassment, insults, personal or political attacks, and publishing others' private information are not acceptable, in project spaces or when representing the project elsewhere.

## Reporting

Report unacceptable behavior privately to the maintainer ([@juangarcia83](https://github.com/juangarcia83)) through GitHub. All reports will be reviewed promptly and handled confidentially. Enforcement follows the [Contributor Covenant enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
